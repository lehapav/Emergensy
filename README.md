# Симулятор послеаварийных режимов для анализа отключения линий 500 кВ

## Описание
Программа моделирует работу электрической сети, рассчитывает установившиеся режимы (напряжения, токи, потоки мощности) с помощью библиотеки pandapower и визуализирует мнемосхему с цветовой индикацией аварий.

## Технологии
- Python 3
- pandapower – расчёт потокораспределения
- ttkbootstrap – графический интерфейс
- SQLite – хранение данных

## Установка и запуск
1. Установите зависимости: `pip install -r requirements.txt`
2. Запустите: `python main.py`
